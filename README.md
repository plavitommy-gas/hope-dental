# Hope Dental — dr Nada Bojić

Jednostranični demo sajt za stomatološku ordinaciju **Hope Dental** (Voždovac, Beograd) — parodontologija i opšta stomatologija + estetska medicina (botoks, fileri, PRP, skinbooster).

Statički sajt: `index.html` + `styles.css` + `script.js`, bez build koraka.

## Lokalni pregled
```bash
npx serve -l 5178 .
```
pa otvoriti `http://localhost:5178/`.

## Struktura
- `index.html` — kompletna stranica (hero, usluge, estetska medicina, rezultati, timeline procesa, galerija, utisci, tim, FAQ, kontakt forma, mapa)
- `styles.css` — lila brend, responsive, animacije
- `script.js` — preloader, nav, scroll reveal, timeline, galerija + lightbox, forma
- `assets/` — slike korišćene na sajtu

Demo · predlog redizajna.
